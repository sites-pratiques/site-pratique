Downloadzeit

Geben Sie die Dateigröße und Ihre Geschwindigkeit ein, um die Dauer der Übertragung zu schätzen.

—

Wie funktioniert das?

Die Zeit ergibt sich aus der in Bit umgerechneten Dateigröße geteilt durch die Geschwindigkeit in Bit pro Sekunde. Internettarife werden mit Geschwindigkeiten in Megabit pro Sekunde (Mbit/s) beworben; Dateigrößen werden in Byte angegeben (1 Byte = 8 Bit). Eine Geschwindigkeit von 100 Mbit/s entspricht also etwa 12,5 MB pro Sekunde. Verwendet werden dezimale Einheiten: 1 MB = 1.000.000 Byte.

Werbung

Wichtige Einschränkungen

  • Die tatsächliche Geschwindigkeit liegt fast immer unter der beworbenen: WLAN, Netzüberlastung, entfernter Server.
  • Das Ergebnis ist ein theoretisches Minimum, ohne Unterbrechung oder Servergrenze.

Die Berechnung erfolgt in Ihrem Browser: Es wird nichts an einen Server gesendet. Der Inhalt wurde ohne bestimmte externe Quelle verfasst; prüfen Sie bei wichtigen Entscheidungen eine offizielle Quelle.
