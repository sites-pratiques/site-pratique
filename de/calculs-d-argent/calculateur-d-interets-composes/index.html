Zinseszinsrechner

Geben Sie ein Startkapital, eine monatliche Einzahlung, eine jährliche Rendite und eine Laufzeit ein, um die Entwicklung Ihrer Ersparnisse zu simulieren.

—

Wie funktioniert das?

Der Jahreszins wird in einen äquivalenten Monatszins umgerechnet: i = (1 + Zins)1/12 − 1. Das Endkapital beträgt C × (1 + i)n + V × ((1 + i)n − 1) ÷ i, wobei n die Anzahl der Monate und V die monatliche Einzahlung ist (am Monatsende eingezahlt). Die Zinsen sind das Endkapital abzüglich der Gesamteinzahlung.

Werbung

Wichtige Einschränkungen

  • Eine konstante Rendite ist eine Annahme: Reale Geldanlagen schwanken, und das Kapital kann sinken.
  • Steuern, Sozialabgaben, Gebühren und Inflation werden nicht berücksichtigt.
  • Unverbindliche Simulation, keine Anlageberatung.

Die Berechnung erfolgt in Ihrem Browser: Es wird nichts an einen Server gesendet. Der Inhalt wurde ohne bestimmte externe Quelle verfasst; prüfen Sie bei wichtigen Entscheidungen eine offizielle Quelle.
