Download time

Enter the file size and your speed to estimate how long the transfer will take.

—

How does it work?

The time is the file size converted to bits divided by the speed in bits per second. Internet plans advertise speeds in megabits per second (Mb/s); file sizes are in bytes (1 byte = 8 bits). A speed of 100 Mb/s therefore corresponds to about 12.5 MB per second. The units used are decimal: 1 MB = 1,000,000 bytes.

Limitations to know

  • Real speed is almost always lower than the advertised speed: Wi-Fi, network congestion, remote server.
  • The result is a theoretical minimum, with no interruption or server limit.

The calculation is done in your browser: nothing is sent to a server. Content written without any particular external source; for an important decision, check with an official source.
