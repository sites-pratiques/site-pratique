Bon à savoir sur Windows

  • La touche Windows ouvre le menu Démarrer lorsqu’on l’utilise seule, et sert de base à de nombreux raccourcis système (Windows + E, Windows + L…).
  • L’historique du presse-papiers (Windows + V) doit être activé dans les paramètres de Windows pour fonctionner.
  • Windows + A ouvre les paramètres rapides sous Windows 11 ; la fonction diffère sous Windows 10.
  • Enregistrez votre travail avant d’utiliser Alt + F4, qui ferme la fenêtre active.
  • Sur un ordinateur portable, les touches de fonction (F2, F5…) peuvent nécessiter la touche Fn.

À retenir

Les raccourcis sont des aides pratiques, mais ils ne sont pas identiques dans tous les logiciels. Vérifiez les menus de l’application ou sa documentation si une combinaison ne produit pas l’effet attendu.
