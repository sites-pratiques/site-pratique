Mode d’emploi

Bien utiliser les raccourcis clavier

Un raccourci combine une ou plusieurs touches pour déclencher une commande sans passer par les menus. Voici comment les lire, les tester, les retenir et comprendre pourquoi ils ne fonctionnent pas toujours.

Comment lire une combinaison ?

Le signe « + » signifie qu’il faut maintenir les touches indiquées ensemble. Par exemple, Ctrl + C signifie maintenir Ctrl, appuyer sur C, puis relâcher les touches. Il ne faut pas taper le signe plus.

Sur Mac, la touche ⌘ (Commande) remplace souvent Ctrl dans les applications, mais pas toujours. Les raccourcis peuvent également différer selon la langue du clavier, le logiciel ou la version du système.

Les touches à connaître

  • Ctrl / Contrôle : touche de modification principale sur Windows et Linux.
  • ⌘ Commande : touche de modification principale dans de nombreuses applications macOS.
  • Maj / ⇧ : sert souvent à inverser une action ou à étendre une sélection.
  • Alt / Option (⌥) : donne accès à des commandes complémentaires.
  • Windows : touche avec le logo Windows, base de nombreux raccourcis système.
  • Échap : permet souvent de fermer un menu ou d’annuler une action en cours.

Passer de Windows à Mac

Les actions de base sont les mêmes, seules les touches changent. En règle générale :

  • Ctrl sur Windows correspond à ⌘ sur Mac pour copier, coller, enregistrer ou rechercher ;
  • Alt sur Windows correspond à ⌥ (Option) sur Mac ;
  • Maj correspond à ⇧ sur les deux systèmes ;
  • sur Mac, ⌃ (Contrôle) est une touche distincte, utilisée pour d’autres commandes.

Cette équivalence est une règle générale : elle a des exceptions, notamment dans les raccourcis système. Consultez les raccourcis Windows et les raccourcis Mac pour les combinaisons précises.

Comment les mémoriser ?

  1. Commencez par copier, coller, annuler, enregistrer et rechercher.
  2. Apprenez les raccourcis d’un seul logiciel à la fois.
  3. Pratiquez-les régulièrement plutôt que d’essayer de tout retenir d’un coup.
  4. Gardez cette page en favori et utilisez la recherche du répertoire pour retrouver une commande.

Un raccourci ne fonctionne pas : que vérifier ?

  • L’application active : le raccourci s’applique à la fenêtre ou au champ qui a le focus. Cliquez dans l’application avant d’essayer.
  • La langue ou la disposition du clavier : sur un clavier AZERTY, certains caractères exigent des touches supplémentaires et certaines combinaisons changent.
  • La touche Fn : sur certains ordinateurs portables, les touches F1 à F12 sont associées à des fonctions matérielles (luminosité, volume).
  • La version et la langue du logiciel : les raccourcis à lettre peuvent différer selon la langue de l’interface (par exemple le gras dans Word en français) ; le menu de l’application indique la combinaison à côté de chaque commande.
  • Les conflits : une extension, un logiciel résident ou un paramètre du système peut capter la même combinaison.
  • La fonction désactivée : certains raccourcis, comme l’historique du presse-papiers de Windows, doivent être activés dans les paramètres.

Si les combinaisons de touches sont difficiles à tenir

Les systèmes d’exploitation proposent des options d’accessibilité qui permettent de saisir une combinaison touche après touche, sans les maintenir ensemble. Sous Windows, ces « touches rémanentes » se règlent dans les paramètres d’accessibilité ; sous macOS, une option équivalente existe dans les réglages d’accessibilité. Appuyer cinq fois de suite sur Maj sous Windows propose généralement de les activer.

À savoir : certains raccourcis sont universels dans de nombreuses applications, d’autres sont spécifiques à un logiciel. Si une combinaison ne fonctionne pas, consultez le menu ou l’aide de l’application.
