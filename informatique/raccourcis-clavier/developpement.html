Bon à savoir dans VS Code

  • La palette de commandes (Ctrl + Maj + P) donne accès à toutes les commandes, même sans raccourci.
  • Tous les raccourcis sont modifiables dans le menu « Fichier › Préférences › Raccourcis clavier » (Ctrl + K puis Ctrl + S).
  • Sur un clavier AZERTY, certains caractères (comme l’apostrophe inversée ou la barre oblique) ne sont pas accessibles directement : la combinaison exacte affichée dans le menu de VS Code fait foi.
  • Le formatage du document nécessite un formateur configuré pour le langage utilisé, par exemple via une extension.

À retenir

Les raccourcis sont des aides pratiques, mais ils ne sont pas identiques dans tous les logiciels. Vérifiez les menus de l’application ou sa documentation si une combinaison ne produit pas l’effet attendu.
