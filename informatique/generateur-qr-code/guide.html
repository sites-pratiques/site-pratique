Mode d’emploi

Bien utiliser un QR code

Taille, contraste, correction d’erreur, impression et sécurité : les points qui font la différence entre un QR code qui se scanne du premier coup et un autre.

Que signifie la correction d’erreur ?

Un QR code contient des données de redondance qui permettent de lire le code même s’il est abîmé ou partiellement caché. Il existe quatre niveaux : L (environ 7 % de données récupérables), M (15 %), Q (25 %) et H (30 %). Un niveau élevé rend le code plus robuste mais plus dense. Le niveau M convient à la plupart des usages ; choisissez H pour une surface qui peut être salie ou rayée.

Quelle taille et quelle marge ?

Le QR code doit rester assez grand pour être lu à la distance prévue : comptez au minimum 2 cm de côté pour une lecture de près, davantage pour une affiche. La norme prévoit une zone de silence d’au moins 4 modules blancs autour du code ; l’outil la fixe à 4 par défaut. Pour l’impression, privilégiez le format SVG, qui reste net à toutes les tailles.

Couleurs et contraste

La lecture repose sur le contraste entre les modules et le fond. Des modules foncés sur fond clair sont le choix le plus fiable. Des modules plus clairs que le fond (QR code « inversé ») ne sont pas lus par tous les lecteurs. L’outil vous avertit lorsque le contraste est faible.

Publicité

Sécurité : que vérifier ?

  • Vérifiez l’adresse affichée par votre téléphone avant d’ouvrir un lien scanné, surtout si le QR code vient d’un autocollant ou d’un courrier inattendu.
  • N’affichez un QR code Wi-Fi que dans un lieu de confiance : il révèle le mot de passe.
  • Évitez de coder des informations sensibles dans un QR code destiné à être diffusé.

Tester avant de diffuser

Scannez toujours le QR code avec au moins un téléphone, à la taille finale et sur le support réel (écran, papier). Si la lecture est lente, augmentez la taille, le contraste ou la marge, ou raccourcissez le contenu.

Pour aller plus loin : « QR Code » est une marque déposée de DENSO WAVE INCORPORATED. Le format est décrit par la norme ISO/IEC 18004.
