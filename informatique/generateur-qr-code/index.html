Générateur de QR code gratuit

Créez un QR code pour un lien, un texte, un réseau Wi-Fi, un e-mail, un téléphone ou un SMS, puis téléchargez-le en PNG ou en SVG. Tout se passe dans votre navigateur : le contenu n’est jamais envoyé à un serveur.

Contenu du QR code

Réglages

Comment ça marche ?

Un QR code encode une suite de caractères sous forme de carrés noirs et blancs, que l’appareil photo d’un téléphone sait lire. Choisissez le type de contenu, saisissez les informations : l’aperçu se met à jour à chaque modification. Le QR code obtenu est statique : il contient directement votre contenu, n’expire jamais et ne dépend d’aucun service.

Les types de contenu

  • Lien ou texte : une adresse web ou n’importe quel texte.
  • Réseau Wi-Fi : permet à un téléphone de se connecter sans saisir le mot de passe.
  • E-mail, téléphone, SMS : ouvrent l’application correspondante avec les champs préremplis.
Publicité

Limites à connaître

  • Plus le contenu est long, plus le QR code est dense et difficile à scanner. Préférez un lien court.
  • Un QR code statique ne peut pas être modifié après impression : vérifiez-le avant de l’imprimer.
  • Un QR code Wi-Fi contient le mot de passe en clair pour quiconque le scanne.
  • Le comportement à la lecture (ouverture du lien, proposition de connexion) dépend de l’appareil et de son application.
  • Cet outil ne propose pas de logo central ni de statistiques de scan.
