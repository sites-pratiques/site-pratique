Tempo di download

Indichi la dimensione del file e la sua velocità per stimare la durata del trasferimento.

—

Come funziona?

Il tempo è la dimensione del file convertita in bit divisa per la velocità in bit al secondo. Le offerte Internet pubblicizzano velocità in megabit al secondo (Mb/s); la dimensione dei file è espressa in byte (1 byte = 8 bit). Una velocità di 100 Mb/s corrisponde quindi a circa 12,5 MB al secondo. Le unità usate sono decimali: 1 MB = 1 000 000 byte.

Pubblicità

Limiti da conoscere

  • La velocità reale è quasi sempre inferiore a quella pubblicizzata: Wi-Fi, saturazione della rete, server remoto.
  • Il risultato è un minimo teorico, senza interruzioni né limiti del server.

Il calcolo viene eseguito nel suo browser: non viene inviato nulla a un server. Contenuto redatto senza una particolare fonte esterna; per una decisione importante, verifichi presso una fonte ufficiale.
