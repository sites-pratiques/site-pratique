Comment ça marche ?

L’image est lue par votre navigateur, redessinée sur un canevas à la taille demandée (le rapport largeur/hauteur est conservé), puis réencodée dans le format choisi. JPEG et WebP compressent avec perte : plus la qualité est basse, plus le fichier est léger. PNG est sans perte, adapté aux captures, logos et images avec transparence. Pour un JPEG, la transparence est remplacée par un fond blanc.

Limites à connaître

  • Les métadonnées (date, appareil, position GPS) ne sont pas conservées dans le résultat.
  • Une image animée (GIF) n’est convertie que sur sa première image.
  • Le format WebP dépend du navigateur ; si votre navigateur ne sait pas l’encoder, un PNG est produit à la place et l’outil vous le signale.
  • Les très grandes images peuvent dépasser la mémoire d’un téléphone ancien.

Le calcul est effectué dans votre navigateur : rien n’est envoyé à un serveur. Contenu rédigé sans source externe particulière ; en cas de décision importante, vérifiez auprès d’une source officielle.
