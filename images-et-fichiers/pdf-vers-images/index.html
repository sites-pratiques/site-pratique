PDF en images

Choisissez un PDF, un format et une résolution : chaque page devient une image que vous pouvez télécharger.

Comment ça marche ?

Le PDF est lu par votre navigateur grâce à la bibliothèque libre PDF.js (licence Apache 2.0), puis chaque page est dessinée sur une image à la résolution choisie. Plus la résolution est élevée, plus l’image est nette et lourde. Le format PNG est sans perte ; JPEG est plus léger mais avec perte.

Publicité

Limites à connaître

  • Le traitement est limité à 50 pages à la fois ; utilisez le champ « Pages » pour traiter un long document par parties.
  • Les PDF protégés par mot de passe sont refusés.
  • Certains PDF (polices non intégrées, images JPEG 2000) peuvent s’afficher imparfaitement.
  • Une navigation moderne est nécessaire : un ancien navigateur peut ne pas afficher le résultat.

Le calcul est effectué dans votre navigateur : rien n’est envoyé à un serveur. Contenu rédigé sans source externe particulière ; en cas de décision importante, vérifiez auprès d’une source officielle.
