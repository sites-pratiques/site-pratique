Images en PDF

Ajoutez vos images, réglez l’ordre et la taille de page, puis téléchargez le PDF obtenu.

    Comment ça marche ?

    Chaque image est lue par votre navigateur (ce qui applique l’orientation des photos), puis intégrée dans une page du PDF avec la bibliothèque libre pdf-lib (licence MIT). En mode « A4 », l’image est réduite pour tenir dans la page et centrée ; en mode « Taille de l’image », la page prend les dimensions de l’image. Les PNG gardent leur transparence ; les autres images sont enregistrées en JPEG.

    Publicité

    Limites à connaître

    • Les images très grandes sont réduites à 4 000 pixels sur leur plus grand côté pour limiter la mémoire utilisée.
    • Les GIF animés ne conservent que leur première image.
    • Le PDF n’est pas compressé : un grand nombre de photos peut donner un fichier volumineux.

    Le calcul est effectué dans votre navigateur : rien n’est envoyé à un serveur. Contenu rédigé sans source externe particulière ; en cas de décision importante, vérifiez auprès d’une source officielle.
